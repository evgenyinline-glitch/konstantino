КОНСТАНТИН ЩЕРБИНИН — САЙТ

1. Распакуйте ВЕСЬ архив.
2. Откройте index.html в браузере. Интернет для сайта и видео не нужен.
3. Сохраните структуру: index.html и папка assets с файлом hero.mp4.
4. Для публикации загрузите содержимое папки на хостинг.

Видео локальное, без затемнения, отображается целиком без обрезки.
Заголовок уменьшен, полупрозрачен; его можно скрыть кнопкой под видео.
Звук включается вручную. Автовоспроизведение зависит от настроек браузера.

Контакты задаются в SITE_CONFIG внутри index.html.
Форма не отправляет данные на сервер. При указанном email открывает почтовое приложение.
